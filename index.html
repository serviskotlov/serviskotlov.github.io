📦 Export / Import
☁️ Návod: Google Drive
Krok 1 — Google Cloud Console
Otvor: console.cloud.google.com
→ Vytvor nový projekt (napr. "ServisKotlov")
Krok 2 — Aktivuj Drive API
APIs & Services → Library
→ Hľadaj "Google Drive API"
→ Klikni Enable
Krok 3 — OAuth súhlas
APIs & Services → OAuth consent screen
→ User Type: External
→ Vyplň názov aplikácie
→ Scopes: pridaj drive.file
→ Test users: pridaj svoj Gmail
Krok 4 — Client ID
APIs & Services → Credentials
→ Create Credentials → OAuth Client ID
→ Application type: Web application
→ Authorised JavaScript origins + redirect URI:
presné adresy nájdeš v Nastaveniach
pod poľom Client ID
→ Skopíruj celý Client ID (končí na
.apps.googleusercontent.com)
💡 Tip
Google prihlásenie nefunguje, keď je aplikácia otvorená ako súbor (file://) — napr. z Files na iPhone. Nahraj ju na GitHub Pages alebo Netlify a otvor cez https://. Bez toho použi Export / Import JSON, ktorý funguje vždy.

📖 Návod – ako začať
Obchodné podmienky · Ochrana osobných údajov
☁️ Návod: Google Drive
Krok 1 — Google Cloud Console
Otvor: console.cloud.google.com
→ Vytvor nový projekt (napr. "ServisKotlov")
Krok 2 — Aktivuj Drive API
APIs & Services → Library
→ Hľadaj "Google Drive API"
→ Klikni Enable
Krok 3 — OAuth súhlas
APIs & Services → OAuth consent screen
→ User Type: External
→ Vyplň názov aplikácie
→ Scopes: pridaj drive.file
→ Test users: pridaj svoj Gmail
Krok 4 — Client ID
APIs & Services → Credentials
→ Create Credentials → OAuth Client ID
→ Application type: Web application
→ Authorised JavaScript origins + redirect URI:
presné adresy nájdeš v Nastaveniach
pod poľom Client ID
→ Skopíruj celý Client ID (končí na
.apps.googleusercontent.com)
💡 Tip
Google prihlásenie nefunguje, keď je aplikácia otvorená ako súbor (file://) — napr. z Files na iPhone. Nahraj ju na GitHub Pages alebo Netlify a otvor cez https://. Bez toho použi Export / Import JSON, ktorý funguje vždy.

👋 Vitaj

Servis kotlov ti postráži termíny servisov a revízií, vyplní protokol a pripomenie zákazníkom, že sa blíži prehliadka.

📅 Termíny – na Prehľade vidíš, kto je po termíne a kto príde na rad.
📋 Protokoly – vyplníš v telefóne, zákazník podpíše na displeji.
📴 Bez signálu – údaje sú v tvojom telefóne, appka funguje aj v pivnici.
Tieto údaje sa zobrazia v hlavičke protokolov, ponúk a v pripomienkach zákazníkom. Neskôr ich zmeníš v Nastaveniach.

Hotovo. Ako chceš začať?

Ukážkoví zákazníci sa pritom odstránia.
Odstrániš ich neskôr v Nastaveniach, do limitu sa nepočítajú.
Súbor .json, ktorý si si predtým uložil cez Zálohu. S verziou PRO sa dá obnoviť aj z Google Drive (Nastavenia → Google Drive).
